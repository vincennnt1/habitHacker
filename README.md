# habitHacker

**Created for the 2025 SpurHacks Hackathon**

habitHacker is a personal habit and mood tracking tool that leverages a custom-trained NLP model to provide insights into your daily emotions.

## Features
- Uses a custom NLP model with over **90% accuracy** to detect emotions from daily diary entries.
- Connects your mood to external variables to uncover patterns.
- Provides actionable insights to help you understand how daily habits affect your emotional well-being.

## Usage

1. Enter your daily diary entries into the app.  
2. The NLP model will analyze the entry and assign an emotion.  
3. Track your mood trends over time and see how different factors influence your emotional state.  

## Tech Stack

- **Python**  
- **Natural Language Processing** (custom NLP model)  
- **Data analysis libraries** (e.g., pandas, numpy, scikit-learn)
- **Kivy** (GUI for Windows)
- **Joblib** (for saving NLP models)
